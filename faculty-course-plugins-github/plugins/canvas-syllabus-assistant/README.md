# Canvas Syllabus Assistant

This plugin revises an instructor-supplied syllabus, reconciles supplied policies and term dates, creates a change log, and prepares accessible content for manual transfer into Canvas.

It does not invent missing information or publish directly to Canvas.

See the repository-level [installation guide](../../INSTALL.md), [usage guide](../../docs/Faculty%20Plugin%20Usage%20Guide.docx), and [test guide](../../TESTING.md).

# Canvas Handoff

Produce content for manual instructor transfer; do not modify Canvas directly.

## Canvas-ready content

- Create an HTML fragment rather than a complete webpage. Do not include `<html>`, `<head>`, scripts, forms, tracking, or external stylesheets.
- Use semantic headings in order, beginning with `<h2>` unless the instructor requests another starting level.
- Use paragraphs, lists, and simple tables only when appropriate.
- Use descriptive link text and preserve only verified URLs.
- Do not encode important meaning by color alone.
- Avoid inline styling unless needed to preserve a simple, accessible presentation.

## Separate Canvas updates

List information that may also require changes outside the Syllabus description, including:

- assignment due dates;
- calendar events;
- module availability dates;
- quiz or discussion dates;
- assignment-group weights;
- linked files; and
- published/unpublished status.

Remind the instructor to use Student View and test links after pasting the approved content.

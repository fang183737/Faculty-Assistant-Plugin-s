# Syllabus Accessibility Checklist

Check the generated draft for:

- a logical heading hierarchy without skipped levels;
- descriptive links instead of generic phrases such as “click here”;
- meaningful list markup for grouped items;
- simple tables with header cells when tabular structure is necessary;
- instructions that do not depend on color, position, shape, or sensory language alone;
- clear, concise paragraphs and consistent terminology;
- alternative text requirements for meaningful images;
- captions or transcripts required for linked media; and
- readable document titles and filenames.

Report any item that cannot be verified from the supplied files. Do not claim formal accessibility compliance solely from an automated review.

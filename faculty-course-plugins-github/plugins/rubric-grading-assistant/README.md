# Rubric Grading Assistant

This plugin drafts a criterion-by-criterion review of one submission using instructor-supplied assignment instructions and a final rubric.

It produces proposed scores and feedback for instructor review. It does not enter grades, make a final academic decision, or determine AI use or misconduct.

See the repository-level [installation guide](../../INSTALL.md), [usage guide](../../docs/Faculty%20Plugin%20Usage%20Guide.docx), and [test guide](../../TESTING.md).

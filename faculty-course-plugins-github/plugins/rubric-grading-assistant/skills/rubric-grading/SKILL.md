# Rubric-Based Grading

Help the instructor apply their rubric consistently while keeping every score and comment subject to instructor approval.

## Required sources

Locate sources only inside the workspace the user selected. Prefer clearly named files for:

- assignment instructions;
- the final rubric;
- one submission; and
- optional instructor grading notes or de-identified feedback examples.

If the rubric, assignment instructions, or submission is missing, ask for that item before proposing a score. Never search outside the selected workspace for student material.

## Privacy gate

Before reading a real submission, check whether it appears to contain a name, student number, email address, accommodation information, or other sensitive data. If it does, pause before substantive analysis and ask the instructor to confirm that the tool and account are institution-approved for that data or to provide a de-identified copy.

Read [references/privacy-and-grading-safety.md](references/privacy-and-grading-safety.md) whenever real student work is involved or approval is uncertain.

## Workflow

1. Identify the source files and state which rubric controls the evaluation.
2. Check the rubric scale, point totals, and any explicit penalties. Flag conflicts instead of silently resolving them.
3. Evaluate every criterion separately using evidence from the submission.
4. Distinguish direct evidence, reasonable interpretation, and uncertainty.
5. Calculate a proposed total and verify the arithmetic.
6. Draft respectful, specific, growth-oriented feedback aligned with the proposed scores.
7. Put judgment calls, missing evidence, and policy questions in an instructor-only review section.
8. Save results as new drafts. Never modify the submission or overwrite instructor source files.

Use [assets/grading-report-template.md](assets/grading-report-template.md) as the default output structure. If the workspace already has an output convention, follow it. Otherwise create an `AI-Drafts` folder and use a neutral filename that does not contain the student's name.

## Boundaries

- Label all scores as proposed until the instructor approves them.
- Use only requirements present in the supplied materials.
- Do not infer identity, intent, effort, disability, or personal circumstances.
- Do not determine plagiarism, cheating, or unauthorized AI use.
- Do not penalize grammar, mechanics, format, lateness, or citations unless an applicable source explicitly authorizes it.
- Do not compare the submission with other students.
- Do not enter grades into an LMS or send feedback to a student.
- Do not expose instructor-only notes in student-facing feedback.

## Calibration

When the user asks to calibrate the workflow, read [references/calibration.md](references/calibration.md). Calibration examples must be fictional, properly de-identified, or institutionally approved.

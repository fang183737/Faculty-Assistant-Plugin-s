# Rubric Calibration

Use calibration to compare the workflow's proposed scoring with the instructor's professional judgment before current student work is processed.

1. Select at least three fictional, de-identified, or approved samples representing strong, developing, and substantially incomplete performance.
2. Have the instructor score each sample independently.
3. Run the rubric workflow without revealing the instructor's scores.
4. Compare criterion-level ratings, rationales, and evidence—not only totals.
5. Record recurring interpretation differences and revise the rubric guidance or instructor notes.
6. Repeat the samples after revisions.

Do not force exact agreement where the rubric legitimately requires professional judgment. The goal is to make differences visible and explainable.
